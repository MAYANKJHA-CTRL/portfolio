## 🚀 Deployment

This portfolio is deployed using **GitHub Pages**.

### Steps to Deploy

```bash
1. Create a GitHub repository
2. Upload project files
3. Go to Settings → Pages
4. Select branch: main
5. Save and deploy
```

Your website will be live at:

```bash
https://YOUR-USERNAME.github.io/
```
